# 通用 OCR 验证记录

## 实现

新增 `generic` 档案，使用 RapidOCR + ONNX Runtime，不依赖固定显示屏模板。

处理流程：

1. 抽样帧检测屏幕文字和主读数区域；
2. 自动尝试 0°、90°、180°、270°；
3. 识别数字并过滤日期、时间、菜单、百分比和最大值；
4. 用天平标准砝码判断主读数和 `g/mg`；
5. 固定 ROI 后只执行文字识别，避免每帧重复完整检测；
6. 按稳定时间聚合九次称量。

未知天平编号会自动回退到 `generic`。已知 F001/F002/F003 仍优先使用专用档案；
当专用档案少于九次时，也会尝试通用档案。

## 图形屏截图验证

| 样本 | 通用 OCR 结果 | 置信度 |
| --- | --- | --- |
| Sartorius 图形屏 | 49.99994 g | 93.5% |
| Sartorius 图形屏（带“原图下载失败”遮罩） | 49.99988 g | 90.2% |
| Mettler 图形屏（侧转拍摄） | 20.00025 g | 97.7% |

三张图形屏均正确提取主读数并排除菜单、日期和遮罩文字。

## 七段数码管验证

对现有 F001、F002、F003 七段码视频使用 `generic` 整片识别，均未得到九次称量。
这类显示屏继续使用专用模板，精度和速度更高：

- `f001` / `f001_mg`
- `f002a` / `f002b` / `f002c`
- `f003`

## 结论

通用 OCR 已可用于普通图形屏、触摸屏和新品牌数字文字界面。七段数码管不是通用
文字 OCR 的强项，不能删除现有专用档案；最终方案采用“专用模板优先、通用 OCR 兜底”
的混合架构。
