## 6. 视频上传与异步识别

- [ ] 选择错误扩展名时被拒绝。
- [ ] 超过 500MB 时被拒绝。
- [ ] 上传后视频状态从 `UPLOADED` 进入 `ANALYZING`。
- [ ] 提交识别接口后约 1 秒内返回，不阻塞直到识别完成。
- [ ] 前端可以轮询并显示识别中状态。
- [ ] 上传时填写的实际拍摄开始时间正确。
- [ ] 识别完成后状态为 `ANALYZED` 或 `FAILED`。
- [ ] 识别失败时有明确原因。
- [ ] 识别失败后可以重新识别。
- [ ] 已生成校验记录的同一视频不会重复建单。
- [ ] 系统重启后不存在长期停留在 `ANALYZING` 的视频。
- [ ] 后端启动恢复会把遗留的 `ANALYZING` 视频标记为 `FAILED`，页面可重新识别。
- [ ] 验证线程池满或任务异常时，视频最终不会永久卡住。
