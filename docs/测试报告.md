# 天平校验视频分析系统 测试报告

> 对应批次：3、5、6、7、8
> 测试对象：后端接口、前端页面、判定与复核规则、交付脚本

## 一、测试范围与方法

测试分三层，分别覆盖不同风险：

1. **独立校验**：把不依赖数据库与 Spring 上下文的规则（判定换算、复核状态、天平清单校验、记录表渲染）抽成纯函数，用独立 runner 直接验证，可在没有数据库的环境执行。
2. **接口冒烟**：启动后端与数据库后，用 PowerShell 脚本按角色依次调用接口，覆盖权限、状态流转、查询过滤与异常分支。
3. **浏览器检查**：用 Playwright 驱动浏览器验证页面交互（脚本不在本仓库内，结果记录在本报告）。

测试数据使用初始化脚本中的两台天平（F001 单量程 220 g/0.1 mg、F002 双量程 120 g/0.1 mg 与 40 g/0.01 mg）、四个演示账号，以及脚本运行时创建的临时天平与模板。

## 四、缺陷记录

| 编号 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| D1 | 登录失败时前端刷新页面，看不到"账号或密码错误" | 后端返回 HTTP 200 + 业务码 401，前端按会话过期处理 | 批次 3 修复：异常处理器按业务码返回 401/403/404/413/400 |
| D2 | 记录表导出在权限不足时可能返回 406 | 接口用 `produces=text/html`，异常处理器无法写 JSON | 批次 6 修复：改为显式 Content-Type + ResponseEntity |
| D3 | 天平停用后编辑其历史记录，分度值与量程不回显 | 清单接口只返回启用天平 | 批次 7 修复：编辑页按编号补查天平详情 |
| D4 | `mvnw test` 无法执行 | 离线仓库缺 JUnit 与 surefire 依赖 | 未修复，规则改用独立 runner 验证，JUnit 待恢复 |
| D5 | 识别读数准确率未达标 | 七段码多位数字配对与单位识别未完成 | 批次 4 进行中，不影响其余批次验收 |

## 五、未覆盖与风险

- **并发**：未做多用户并发上传与复核的压力测试；会话存储为单机内存（单实例部署下可接受）。
- **浏览器兼容**：仅验证 Chromium 内核；未覆盖 Firefox、Safari 与低版本 IE 场景。
- **大文件边界**：500MB 上限仅在 21.5MB 样本上验证，未做满额上传测试。
- **识别链路**：批次 4 未完成，视频状态仍停留在 UPLOADED，识别回调与九次读数落库未联调。
- **PDF 归档**：记录表用浏览器打印生成 PDF，未做服务端 PDF 生成，版面依赖浏览器打印设置。
- **权限矩阵**：覆盖了主要越权路径（检验人员看他人记录、复核人员建记录、非管理员看日志），未穷举全部接口组合。

## 六、结论

批次 3、5、6、7、8 的功能均有用例覆盖，独立校验与交付脚本在交付验证环境全部通过；接口冒烟脚本已就绪，需在数据库就绪的环境按 README 第八节执行。批次 4 的识别准确率是当前唯一未达标项，需在后续迭代中解决。

建议验收时按《交付清单》的步骤逐项操作，并在验收现场执行 `scripts/test-all.ps1` 留存输出。
