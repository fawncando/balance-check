# 天平校验视频分析系统 测试报告

> 对应批次：3、4、5、6、7、8
> 测试对象：后端接口、前端页面、视频识别、判定与复核规则、交付脚本

## 一、测试范围与方法

测试分三层，分别覆盖不同风险：

1. **独立校验**：把不依赖数据库与 Spring 上下文的规则（判定换算、复核状态、天平清单校验、记录表渲染）抽成纯函数，用独立 runner 直接验证，可在没有数据库的环境执行。
2. **接口冒烟**：启动后端与数据库后，用 PowerShell 脚本按角色依次调用接口，覆盖权限、状态流转、查询过滤与异常分支。
3. **浏览器检查**：`scripts/browser-acceptance.ps1` 通过 Edge DevTools 协议驱动真实页面，
   验证登录、上传、自动识别、草稿、提交和记录查询，并自动生成截图。

测试数据使用初始化脚本中的两台天平（F001 单量程 220 g/0.1 mg、F002 双量程 120 g/0.1 mg 与 40 g/0.01 mg）、四个演示账号，以及脚本运行时创建的临时天平与模板。

## 四、缺陷记录

| 编号 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| D1 | 登录失败时前端刷新页面，看不到"账号或密码错误" | 后端返回 HTTP 200 + 业务码 401，前端按会话过期处理 | 批次 3 修复：异常处理器按业务码返回 401/403/404/413/400 |
| D2 | 记录表导出在权限不足时可能返回 406 | 接口用 `produces=text/html`，异常处理器无法写 JSON | 批次 6 修复：改为显式 Content-Type + ResponseEntity |
| D3 | 天平停用后编辑其历史记录，分度值与量程不回显 | 清单接口只返回启用天平 | 批次 7 修复：编辑页按编号补查天平详情 |
| D4 | `mvnw test` 无法执行 | 离线仓库缺 JUnit 与 surefire 依赖 | 未修复，规则改用独立 runner 验证，JUnit 待恢复 |
| D5 | F002 六位读数的小数点与量程归属错误 | `2000.08 mg` 与 `20000.1 mg` 数字串长度相同，两个量程共用同一砝码组 | 已修复：按数字区左边缘选显示档案，按可承载标称值的最小量程归组；三段视频及真实后端链路均通过 |
| D6 | 手机入口二维码指向 WSL 虚拟网卡地址，手机无法访问 | 取 site-local 地址后按字符串排序，`172.30.144.1`（vEthernet WSL）排在 `192.168.0.111`（WLAN）之前；Java 的 `isVirtual()` 识别不出 Hyper-V 网卡 | 已修复：优先用默认路由出口地址，过滤 WSL/Hyper-V/VMware 等虚拟网卡并排除 169.254 地址；新增 5 项独立校验（LanAddressCheck），实测返回 192.168.0.111 |
| D7 | 手机扫码登录后仍进入电脑工作台 | 登录页默认回退到 `/workbench`，部分扫码浏览器丢失 redirect 查询参数 | 已修复：手机客户端默认进入 `/mobile`；移动设备误入 `/workbench` 时自动切回手机页；新增 4 项前端路由测试 |

## 五、未覆盖与风险

- **并发**：已完成 3 路识别与 6 路提交/复核验证；会话仍为单机内存，多实例部署需要共享会话。
- **浏览器兼容**：仅验证 Chromium 内核；未覆盖 Firefox、Safari 与低版本 IE 场景。
- **大文件边界**：500MB 上限仅在 21.5MB 样本上验证，未做满额上传测试。
- **识别泛化**：目前覆盖 F001、F002 的三段固定机位样本；新增机位或设备需要重新标定模板和显示档案。
- **PDF 归档**：服务端 PDF 已实现；当前为 A4 光栅页面，文字不可检索，如后续需可搜索文本可再引入字体子集库。
- **权限矩阵**：覆盖了主要越权路径（检验人员看他人记录、复核人员建记录、非管理员看日志），未穷举全部接口组合。

## 六、结论

批次 3 至 8 的功能均有用例覆盖。识别已升级为异步任务，并完成二维码身份核验、置信度与异常帧标记、并发压力测试和服务端 PDF。当前主要边界是字符模板仅覆盖现有固定机位设备。

建议验收时按《交付清单》的步骤逐项操作，并在验收现场执行 `scripts/test-all.ps1` 留存输出。
